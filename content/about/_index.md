I'm a third year BSc Games Programming student at the University of East London predicted to graduate with a First, with a focus on Gameplay Programming. I'm a dedicated developer with a lot of experience in Godot, Unreal Engine, and C++ programming. I also have a Associate's Degree in Computer Science from Howard Community College.

## Experience
Most of my Unreal Engine experience is with my uni coursework. From [making an inventory system](/devlogs/inventory-demo) to [developing a full-scale indie game](/devlogs/game-studio-1) I have a lot of good stuff to show. I'm most proficient when it comes to gameplay systems, such as inventories, game saving, and character progression. I also have done a lot of UI programming to go with these features. I love working on clean systems that feel seamless to the user experience.

I also have a lot of C++ experience outside of Unreal Engine. Last year I did the [Advent of Code 2025](/devlogs/advent-of-code-2025), and before that I made a [3D game using the Raylib graphics library](/games/tank-game). I've been using C++ for smaller personal projects and programming problems as well. I'm very skilled with object oriented programming, and use advanced techniques including polymorphism, interfaces, and data structures. I frequently maintain my code and focus a lot on readability as I always want to be able to come back and immediately understand old code.

I have done a lot of game jams (events where participants have a limited amount of time to develop a game) as well. I have done the GMTK game jam every year since 2023, as well as some others. I work very well even under the tight jam deadlines. I recently participated in the [Ukie Student Game Jam 2026](/games/ukie-2026) which had a 32 hour deadline. I was responsible for all programming within my team, and I'm very proud of the game we managed to develop in such a short time.
