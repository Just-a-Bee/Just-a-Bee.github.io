## Experience
#### [Unreal Engine 5](/tags/unreal-engine-5)
Currently I'm working as a freelance programmer on [Deathbeds](/games/deathbeds-prototype), an isometric wave-survival game planned for an eventual Steam release. My previous experience includes [making an inventory system using C++](/devlogs/inventory-demo) and [developing a first-person metroidvania](/devlogs/game-studio-1). As a gameplay systems programmer, my goal is to make the main features of the game in a way that is maintainable and enables designers to freely utilize the tools available to them.
#### [C++](/tags/c++)
I focused [my uni dissertation](/devlogs/dissertation) on Game AI programming. My goal was to program advanced strategy game AI in pure C++. I developed the game using Raylib and researched various books and papers to determine effective AI strategies. In the end, I produced AI that was challenging to beat for most players.
Last year I did the [Advent of Code 2025](/devlogs/advent-of-code-2025), and before that I made a [3D game using the Raylib graphics library](/games/tank-game). I've been using C++ for smaller personal projects and programming problems as well. I'm very skilled with object oriented programming, and follow conventional design patterns to keep my code clean, readable, and maintainable. 
#### [Game Jams](/tags/game-jam)
I recently participated in the [Ukie Student Game Jam 2026](/games/ukie-2026) which had a 32 hour deadline. I was responsible for all programming within my team, and I'm very proud of the game we managed to develop in such a short time. We made a sokoban-style puzzler where you play as a mirror called Mirrari. I've participated in the GMTK Game Jam every year since 2023, get ready for my 2026 entry this month! What I love about game jams is that they get me out of my comfort zone. Suddenly I end up making a system for [scoring pictures of bigfoot](/games/bigfoots-big-break), or allowing the player to [add code to an endlessly recurring function](/games/void_loop). I've learned a lot from these experiences and look forward to doing more in the future.
